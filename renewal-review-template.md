# Renewal Review Template

A readiness check to run 90 days before a renewal date, then again at 30 days.

> **Honest framing:** this is a working method for reviewing renewal readiness. My own background is retention and portfolio work — I have not owned renewals or carried a quota — so this template is a way of working, not a record of renewals I personally closed.

## 1. Usage and value

- [ ] Usage trend over the last 90 days: up / flat / down?
- [ ] Value realised this contract period — numbers you can stand behind
- [ ] Features paid for but not used — and why
- [ ] Has the customer said the value out loud? (If not, that's the first job.)

## 2. Stakeholders

- [ ] Decision maker confirmed — same person as at signing?
- [ ] Executive sponsor active in the last 90 days?
- [ ] Champion still in place?
- [ ] Any stakeholder changes since signing?

## 3. Risks

- [ ] Open support issues older than 30 days?
- [ ] Usage drop of more than 20% in any month?
- [ ] Competitor mentioned or evaluated?
- [ ] Budget freeze, restructure, or leadership change?
- [ ] Any promise made at signing that wasn't kept?

## 4. Commercial terms

- [ ] Contract end date and notice period confirmed
- [ ] Pricing/terms changes to flag to the customer early — no surprises
- [ ] Expansion or downgrade conversation needed before renewal?
- [ ] Procurement process and timeline understood

## 5. Decision

| Outcome | Criteria |
| --- | --- |
| **Ready** | Value proven, stakeholders engaged, no open risks |
| **Needs work** | Value is there but a risk needs a plan — owner + date |
| **At risk** | Value unclear or a key risk is unaddressed — escalate, use the churn-risk triage prompt |

## After the review

- Record the decision, the risks, and the plan in the account notes.
- Tell the customer the renewal is coming — early and plainly. Nobody likes a surprise renewal conversation.
